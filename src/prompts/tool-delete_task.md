# Google Tasks — Удалить задачу

Удалить задачу по её ID.

## КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО
- **Никогда не удаляй задачи без ПОВТОРНОГО подтверждения пользователя**
- Покажи пользователю какую именно задачу ты собираешься удалить и дождись явного ответа "да, удали"
- **Никогда не удаляй задачу в рамках цепочки действий** — всегда прерывайся и запрашивай подтверждение

## When to Use
- Пользователь явно и дважды подтвердил удаление конкретной задачи

## Parameters
- `tasklist_id`: ID списка (по умолчанию `@default`)
- `task_id`: ID задачи (обязательно, из `get_tasks`)

## Жёсткие правила
- Перед вызовом всегда получай `task_id` через `get_tasks`. Запрещено угадывать ID
- Покажи задачу пользователю (название, дату) и запроси явное подтверждение
- Только после повторного явного "да, удали" — выполняй удаление

## Ответ при успехе
"Задача успешно удалена"
