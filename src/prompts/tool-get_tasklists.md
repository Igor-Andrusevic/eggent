# Google Tasks — Список задачников

Получить список всех задачников (списков задач) пользователя для поиска их tasklist_id.

## When to Use
- Пользователь упомянул конкретный список задач (по имени)
- Нужно найти tasklist_id для последующих операций
- Пользователь хочет узнать, какие списки задач у него есть

## Жёсткие правила
- Если список не указан пользователем, всегда используй дефолтный ID: `@default`
- Если пользователь упомянул конкретный список, сначала вызови этот инструмент, найди совпадение по имени и получи нужный `tasklist_id`

## Return Format
Список задачников с их ID. Пример:
```
Found 2 task list(s):

[1] My Tasks (ID: abc123)
[2] Work (ID: def456)
```
