# Google Tasks — Создать задачу

Создать новую задачу в Google Tasks.

## When to Use
- Пользователь просит добавить задачу или напоминание БЕЗ конкретного времени (только дата)
- Пользователь говорит "запиши" или "добавь в список"

## КРИТИЧЕСКИ ВАЖНО — Время vs Задачи
- **Google Tasks НЕ поддерживает время (часы/минуты)** — только дату
- Если пользователь указал конкретное время (например "в 19:00"), **НЕ ИСПОЛЬЗУЙ create_task** — вместо этого создай событие через `calendar_create_event`
- Единственное исключение: если пользователь явно просит именно Google Tasks и время — тогда укажи время в поле `notes`, но предупреди, что Tasks не покажет время в календаре

## Parameters
- `tasklist_id`: ID списка (по умолчанию `@default`)
- `title`: Название задачи (обязательно)
- `due`: Дата выполнения (опционально, ТОЛЬКО дата без времени)
- `notes`: Описание или заметки (опционально)

## КРИТИЧЕСКИ ВАЖНО — Формат даты
- Значение `due` передаётся строго в формате: `YYYY-MM-DDT00:00:00.000Z`
- Рассчитывай дату на основе локального часового пояса пользователя, не допускай сдвига даты назад из-за UTC
- Пример: если пользователь в Москве (UTC+3) говорит "на завтра", а сегодня 5 июля — ставь 2026-07-06T00:00:00.000Z
- Если пользователь не указал дату, не передавай поле `due`

## Ответ при успехе
"Задача '[Название]' успешно создана"

## Пример
```
tasklist_id: "@default"
title: "Подготовить отчёт"
due: "2024-01-20T00:00:00.000Z"
notes: "Включить статистику за неделю"
```
