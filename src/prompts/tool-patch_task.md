# Google Tasks — Обновить задачу

Обновить свойства задачи или отметить её как выполненную.

## When to Use
- Пользователь хочет изменить название/дату задачи (без времени)
- Пользователь хочет отметить задачу как выполненную ("заверши задачу Х")
- Пользователь хочет вернуть задачу в активные

## КРИТИЧЕСКИ ВАЖНО — Время vs Задачи
- **Google Tasks НЕ поддерживает время (часы/минуты)**
- Если пользователь хочет добавить/изменить время задачи → предложи создать событие через `calendar_create_event` или `calendar_update_event`

## Parameters
- `tasklist_id`: ID списка (по умолчанию `@default`)
- `task_id`: ID задачи (обязательно, из `get_tasks`)
- `status`: `"needsAction"` (активна) или `"completed"` (выполнена)
- `title`: Новое название (опционально)
- `due`: Новая дата в формате `YYYY-MM-DDT00:00:00.000Z` (опционально, ТОЛЬКО дата)

## Жёсткие правила
- Перед вызовом всегда получай `task_id` через `get_tasks`. Запрещено угадывать ID
- Для выполнения задачи передай `status: "completed"`
- Для возврата в активные передай `status: "needsAction"`
- Если найдено несколько задач с одинаковым названием, попроси пользователя уточнить

## Формат даты
Строго `YYYY-MM-DDT00:00:00.000Z`. Время всегда UTC полночь.
Учитывай часовой пояс пользователя — не допускай сдвига даты назад.

## Ответ при успехе
"Задача '[Название]' успешно выполнена" — если `status: "completed"`
"Задача '[Название]' успешно обновлена" — во всех остальных случаях
