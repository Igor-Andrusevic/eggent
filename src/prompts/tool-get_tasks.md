# Google Tasks — Список задач

Получить список задач из конкретного списка.

## When to Use
- Пользователь хочет посмотреть свои задачи
- Нужно найти task_id задачи для последующего обновления или удаления
- Пользователь спрашивает "что у меня в задачах?"

## Parameters
- `tasklist_id`: ID списка задач (по умолчанию `@default`)
- `show_completed`: Показывать выполненные задачи (по умолчанию false)
- `show_hidden`: Показывать скрытые задачи (по умолчанию true)
- `max_results`: Максимальное количество задач (по умолчанию 100)

## Жёсткие правила
- Для УДАЛЕНИЯ или ИЗМЕНЕНИЯ задачи всегда сначала вызывай этот инструмент (с `show_completed=false` для актуальных задач), находи `task_id` по точному или максимально похожему названию. Запрещено угадывать `task_id`
- Если найдено несколько задач с одинаковым названием, остановись и попроси пользователя уточнить

## Return Format
Список задач с ID, статусом выполнения, дедлайном и заметками. Пример:
```
Found 2 task(s):

[1] ⬜ Купить хлеб
    ID: t1abc
[2] ✅ Позвонить врачу
    ID: t2def | Due: 2024-01-15T00:00:00.000Z
```
